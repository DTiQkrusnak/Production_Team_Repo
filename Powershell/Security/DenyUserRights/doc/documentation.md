### Functions
___
#### Get-ActiveUser
>Gets all active accounts from system and returns only those found in provided list

#### Set-AclRule
>Adds/Removes file system rights on files or directories

#### Remove-AclForUser
>Remove all ACL rules Allow/Deny that are matching provided identity

#### Remove-ApplicationPackagesFromAcl
>Remove all ACL rules that are matching ALL APPLICATION PACKAGES and ALL RESTROCTED APPLICATION PACKAGES identities
